5. Collapse source-status records into one query module

Speculative in-process

Application/Features/Sources/ListSourcesHandler.cs · SourcePolicy.cs · SourceGate.cs · SourceQuotaUsage.cs · SourceCircuit.cs · SourceStatusResponse.cs · Scraping/SourceSettingsCatalog.cs · SourceSettings.cs · Infrastructure/Configuration/SourceSettingsMapper.cs

After

catalog stays the retained seam; single-use records fold in

Problem: Answering "can this source run?" bounces between catalog, policy, quota, circuit, and four single-use records.

Solution: Fold status records into one module with a single deep query interface.

  • locality: run-readiness logic in one module
  • fewer modules, same knowledge
  • one query interface to test
